# Publishing routines and guides

Duplicate the template in either `routines/` or `guides/`. Give the copy a lowercase name such as `weekly-prep.md`, change the first heading to your title, and write the entry in Markdown. Numbered filename prefixes are optional if you want a particular order.

The preview lists entries at `/personal/routines`. Publish by committing the file and deploying the site as usual. The underscore-prefixed templates are never listed. These entries are public; no browser notes or personal documents are imported.
